# ADR-001: Per-task independent 30 CU budget

## Context

2026-11-11 09:12 — the user corrected the assistant's reading of an 'additional 30 CU' authorisation as a cumulative 60 CU budget (57.50 CU remaining). The correction is: every user-initiated production task gets its own independent 30.00 CU budget (PROJECT_BUDGET_CU = 30.0, PER_SESSION_BUDGET_CU = 25.0, CLEANUP_RESERVE_CU = 0.75). Budgets are never summed across tasks; 30 CU is never a top-up. The old ledger was archived read-only (model_cache/archive/, amend_budget_60cu__VOID.py).

## Implementation

h3_budget.py enforces the caps (the controller refuses project_budget_cu != 30.0); config/budget_policy.yaml mirrors the constants; tests/test_config_contract.py asserts them.

## Consequences

Any future 'add budget' request must be treated as a NEW task with its own 30 CU envelope, or be explicitly re-authorised with a new task_id — never silently added to an old ledger.
