# ADR-002: GitHub repository is Private by default

## Context

The workstation contains production runbooks, internal Drive folder IDs, and detailed operational history. It must be created Private and must never be flipped Public by automation. Model weights, poster binaries, MP4s, credentials, ledgers, and session state are excluded by .gitignore and by the secret scan; the repo must still be private even with those exclusions.

## Implementation

gh repo create --private (when the GitHub identity is verified by the parent agent); .gitignore + CI secret scan enforce the content side.

## Consequences

If a future public release is ever wanted, it requires a separate, explicit user decision and a fresh scrubbed export — not a visibility flip.
