# ADR-003: Flat repo-root compat layout for v0.1.0; package refactor later

## Context

Production modules import each other top-level (from h3_budget import ...) and tests do sys.path.insert(0, str(ROOT)); h3_controller.py inserts reference_v2/ into sys.path for colab_manager. Moving modules into workstation/ packages in the first migration would break every import and test for zero production benefit.

## Implementation

v0.1.0 keeps all verbatim production .py files flat at the repo root. workstation/ exists only as a PLANNED layout document (README.md + PLANNED.md, no stub modules). The refactor is a future PR that must keep all tests green.

## Consequences

Do not create workstation/*.py stubs, and do not rewrite imports in the migration commit.
