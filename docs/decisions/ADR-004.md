# ADR-004: No colab-dfs-ext or other third-party CLI injection

## Context

The user explicitly did not approve the third-party colab-dfs-ext extension. The only GPU channel is the official google-colab-cli 0.7.5, plus two documented, verified vendored patches in patches/google-colab-cli-0.7.5/ (real diffs against the pristine wheel). No curl|bash installs of unaudited code.

## Implementation

h3_controller.py preflight fails closed if either patch is missing from the venv CLI; scripts/verify_patch.py checks the diffs offline; CI never installs the CLI.

## Consequences

Any new CLI patch needs its own patch file, live evidence, and preflight gate — same bar as the two existing patches.
