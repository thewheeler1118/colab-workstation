# ADR-005: Muse is the only AI agent; no Mac GPU relay

## Context

North Star (user correction 2026-11-08, immutable): the only AI agent is Muse; natural language → Muse Code → Muse-managed Python controller + Google Colab CLI → Colab GPU → PNG/MP4 to Muse-accessible persistent storage → release GPU → return results. Antigravity v2 is a technical reference and code source only, never a runtime dependency; the Mac is not a GPU scheduling relay. An earlier 'Mac production execution + Muse dev + Antigravity co-controller' proposal was withdrawn and must not be revived.

## Implementation

This repo contains only the Muse-side controller/worker code. No Mac paths, no Antigravity runtime hooks.

## Consequences

Linux VM risks (semi-persistent home, no process keep-alive, unvalidated OAuth storage, CLI not preinstalled) are implementation risks, not reasons to change architecture. A genuinely blocking limitation needs evidence and a BLOCKER label.
