# Patches for google-colab-cli 0.7.5

Two vendored patches against the **official** `google-colab-cli==0.7.5`.
Both are real unified diffs generated by diffing the pristine 0.7.5 wheel
(downloaded from PyPI) against the patched venv copy, and verified with
`git apply --check` plus a byte-identical round-trip against the patched
venv files. They patch the venv copy only: rebuilding the venv or
upgrading the CLI loses them, and `h3_controller.preflight` fails closed
before any GPU is requested if either is missing.

## proxy_post_body.patch — empty-POST 411 workaround (2026-11-11)

- File: `colab_cli/client.py`, `Client._issue_request()`.
- Change: POSTs without an explicit body send `kwargs["data"] = b"{}"`
  (Content-Length: 2, preserved by the VM egress proxy; the Colab backend
  ignores the body). GETs and POSTs with a body are untouched.
- Live evidence: empty POSTs failed 4/4 with 411; with the patch, invalid
  token → 400, valid G4 token → 503, valid A100 token → 200 in 2.7s,
  unassign → 204. Full write-up: `docs/audits/v3_cli_proxy_patch.md`.
- Gate: `h3_controller.cli_post_body_patch_present`.

## drivemount_timeout.patch — remote mount 120s → 600s (2026-11-11)

- File: `colab_cli/commands/automation.py`, `drivemount()` + the
  `INTERACTIVE_AUTOMATION_TIMEOUT_SEC` constant (600 → 660).
- Change: injected remote cell now calls
  `drive.mount('<path>', timeout_ms=600000)`; local automation ceiling 660s
  (60s margin over the remote 600s, because jupyter-kernel-client sets a
  hard wall-clock deadline at execute start).
- Evidence: runs 6–7 failed when authorization finished at ~7–9 min,
  after the 120s kernel timer raised `ValueError: mount failed`. Mock
  tests cover the 300s-auth case. Live mounts in the 2026-11-12 runs
  succeeded with the patched CLI, but authorization completed in 85.1s /
  56.3s — inside the old 120s window — so the 600s path itself is not
  live stress-verified. See `docs/incidents/07-drivemount-timeout-ms-600000.md`.
- Gate: `h3_controller.cli_drivemount_timeout_patch_present`.

## Verification

```bash
python3 scripts/verify_patch.py   # offline: diff shape + controller gates
```

To re-verify against a pristine wheel yourself: download
`google-colab-cli==0.7.5`, extract `colab_cli/client.py` and
`colab_cli/commands/automation.py`, and `git apply --check` each patch
against a copy. Never `curl | bash` anything to install these patches.
